# UProc Zapier Integration — AGENTS.md

> Official UProc integration with [Zapier](https://zapier.com/).
> **Status:** Operational and published on Zapier App Store.

---

## Project structure

```
uproc-zapier/
├── index.js                  # Entry point (authentication + triggers + creates)
├── zapierwrapper.js          # Wrapper for Zapier CLI (build step)
├── package.json              # Dependencies (zapier-platform-core, zapier-platform-cli)
├── package-lock.json
├── .gitignore                # Ignored files
├── CHANGELOG.md              # Version history
├── README.md                 # User documentation
├── definition.json           # Compiled definition (generated by `zapier build`)
├── creates/
│   └── tools.js              # Create: "Select Tool" — runs data process tools
└── triggers/
    ├── b_2_b_lists.js        # Webhook trigger: New Profile Added to B2B List
    ├── data_processed_trigger.js  # Webhook trigger: Data Processed (commented)
    └── web_lists.js          # Webhook trigger: New Webtrack Added to Web List
```

## Authentication

The integration uses **Basic Auth** with email + API key.

Credentials are combined in Basic Auth:
```
Authorization: Basic base64(email:apikey)
```

## Local development

### Install dependencies
```bash
npm install
```

### Run tests locally
```bash
npm test
```

### Build for Zapier
```bash
npx zapier build
```

### Push to Zapier
```bash
npx zapier push
```

### View Zapier logs
```bash
npx zapier logs
```

### Useful commands
```bash
npx zapier describe         # Describe the compiled app
npx zapier validate         # Validate the app
npx zapier upload           # Upload without publishing
npx zapier versions         # List versions
npx zapier env list         # List environment variables
```

## Integration limitations

The integration **only exposes data process tools**:

| Tool type | Supported |
|-----------|-----------|
| Data Process (email validation, enrichment, lookup, etc.) | ✅ Yes |
| Document Ingest | ❌ No |
| Approval Management | ❌ No |
| Campaign Automation | ❌ No |
| Lead Management | ❌ No |
| Customer Care | ❌ No |

## Notes

- Authentication is Basic Auth with email + API key (no OAuth)
- Platform modules are not exposed (only data process)
- No incoming webhooks (Zapier supports them but UProc does not use them in this integration)
- `data_processed_trigger` is commented in `index.js` — uncomment if needed
- The `b_2_b_lists` and `web_lists` triggers use webhook type hook

## ⚠️ Important: Only data process tools

This integration **only exposes Uproc's data process tools** (email validation, enrichment, lookup, etc.).

It does **NOT** expose any of Uproc's platform modules:

| Uproc Module | Available in Zapier? | Why |
|--------------|---------------------|-----|
| **Data Process** (email, company, IBAN, etc.) | ✅ Yes | Core tools (~400+) |
| Document Ingest | ❌ No | Requires file upload + OCR + classification |
| Approval Management | ❌ No | Requires approval workflows |
| Campaign Automation | ❌ No | Requires campaign execution |
| Lead Management | ❌ No | Requires pipeline management |
| Customer Care | ❌ No | Requires ticket management |
| Financial Reconciliation | ❌ No | Requires reconciliation workflows |

## Description

This integration allows Zapier users to connect their Uproc account and run Uproc's data process tools directly from Zapier:

- **Select Tool** (Create) → Run any data process tool (email validation, enrichment, etc.)
- **B2B Lists** (Webhook Trigger) → Trigger when a new profile is added to a Uproc B2B list
- **Web Lists** (Webhook Trigger) → Trigger when a new webtrack is added to a webtracking list

## Modules

### Create: Select Tool (`creates/tools.js`)

Runs any Uproc data process tool from Zapier.

**Flow:**
1. Select tool group (validation, enrichment, etc.)
2. Select specific tool from the group
3. Enter dynamic parameters for the tool
4. Execute the tool and receive the result

**Example:**
```
Zap: New Form Submission → Uproc: Select Tool (check-email-exists) → Send Email
```

### Trigger: B2B Lists (`triggers/b_2_b_lists.js`)

Triggers when a new profile is added to a Uproc B2B list.

**Type:** Webhook (hook)

**Trigger data:**
- Profile data (person)
- Company data (company_general, company_contact, company_financial, company_social, company_technologies)

### Trigger: Web Lists (`triggers/web_lists.js`)

Triggers when a new visit is added to a Uproc webtracking list.

**Type:** Webhook (hook)

**Trigger data:**
- Visit data (IP, user-agent, page, site)
- Geographical data (country, city, coordinates, zipcode)
- Network data (hostname, provider, IP range)
- Reputation data (proxy, TOR, blacklist)
- Associated company data

### Trigger: Data Processed (commented) (`triggers/data_processed_trigger.js`)

This trigger is commented out in `index.js`. Available to uncomment if needed.

**Status:** Disabled (commented at `index.js` line 57)

## Authentication

The integration uses **Basic Auth** with email + API key.

### Required credentials:
- **Email**: Your Uproc email (`username` field in Zapier)
- **API Key**: Your real API key (`api_key` field in Zapier)

### How to obtain credentials:
1. Log in at [app.uproc.io/account/integrations](https://app.uproc.io/account/integrations)
2. Go to **Settings → Integrations**
3. In the **API Credentials** section:
   - **Username** → Your email
   - **API Key (real)** → Your API key

## Generated files

### `definition.json`

This file is automatically generated by `zapier build`. It contains:
- The compiled app definition
- Inline functions (replaced with `$func$...`)
- Embedded sample data (includes PII data if samples have it)

**Important:** Do not edit manually. Always generate with `zapier build`.

### `.zapierapprc`

Zapier Platform CLI configuration file:
```json
{
  "id": 4807,
  "key": "App4807"
}
```

Contains the app ID on the Zapier platform. Do not share publicly.
